# Javascript coding

## Literal template syntax instead of concatenation

Example
```javascript
//Wrong:
'data-entry-id="' + Utils.escapeHtml(entry.id) + '"'
//right:
`data-entry-id="${Utils.escapeHtml(entry.id)}"`
```

### Nested syntax and linebreaks

The result code should look tha same as an html markup syntax would look in terms of line breaks and indentation.
For ternary expressions it's ok to use nest like this:
```javascript
`<div>${someVar}${someOtherVar ? `<span>${someOutput}</span>` : ''}</div>`
```

Avoid long lines. It's better to break like this:
```javascript
`<div class="someClass"
  attr="${aaa}"
  attrB="${bbb}"
  >
  ${someText}
</div>`
```

Regarding the line breaks. Always write like this:
```javascript
  return `
    <div>

    </div>
    `;
```
but NOT like this:
```javascript
  return `<div>

</div>`;
```

Examples
```javascript
//wrong
return '<div class="' + classes.join(' ') + '" data-index="' + Utils.escapeHtml(line.originalIndex) + '"'
      + (line.role ? ' data-role="' + Utils.escapeHtml(line.role) + '"' : '')
      + (line.speakable ? ' data-reading="' + Utils.escapeHtml(line.text) + '"' : '')
      + '><span>' + Utils.escapeHtml(line.text) + '</span></div>';
//right
return `
  <div class="${classes.join(' ')}" 
    data-index="${Utils.escapeHtml(line.originalIndex)}"
    ${line.role ? `
    data-role="${Utils.escapeHtml(line.role)}"` : ''}
    ${line.speakable ? `
    data-reading="${Utils.escapeHtml(line.text)}"` : ''}
    >
    <span>${Utils.escapeHtml(line.text)}</span>
  </div>
  `;
//wrong
    return '<div class="keen-slider__slide js-slide" ' + attrs + '>'
      + info
      + '<div class="sides-count">' + ordered.length + '</div>'
      + '<div class="current-side">' + (current ? current.originalIndex : '') + '</div>'
      + '<div class="slide-inner js-slide-inner">' + sides + '</div>'
      + readingHtml
      + '</div>';
//right
return `
<div class="keen-slider__slide js-slide" ${attrs}>
  ${info}
  <div class="sides-count">${ordered.length}</div>
  <div class="current-side">${current ? current.originalIndex : ''}</div>
  <div class="slide-inner js-slide-inner">${sides}</div>
  ${readingHtml}
</div>
`;
```
